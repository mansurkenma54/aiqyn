# AIQYN — бренд

## 🧭 Неге осы бағыт

AIQYN — машиналық көру өнімі, сондықтан бренд **өзі шығаратын нәрсеге ұқсауы** керек:
детекция overlay-і. Бұрыштық жақшалар мен қауіп-амбер түсі жалпы «AI күлгіні» емес,
доменнің өз тілінен алынған — bounding box пен жол белгісінің түсі.

Атауы да осыны айтады: **«айқын»** — анық, күмәнсіз. Сондықтан белгі бұлыңғырдан
анықтыққа өту сәтін көрсетеді.

## 🎨 Палитра

| Рөлі | HEX | Қайда қолданылады |
|---|---|---|
| Void | `#0A0C0F` | негізгі фон — операторлық экран сияқты |
| Panel | `#14181D` | карточка, панель, кесте жолы |
| Signal | `#FFC933` | табылған ақау, ескерту, негізгі акцент |
| Detect | `#00E0FF` | детекция жақшалары, тор, техникалық сызық |
| Paper | `#E8EDF2` | мәтін |

**Ереже:** амбер тек **шын табылған нәрсеге** қолданылады. Оны декорация ретінде
қолдансаң, оператор ол түске сенуін қояды.

## 🎯 Белгінің мағынасы

Төрт бұрыштық жақша — детекция аймағы. Ішінде сынық сызық солдан оңға қарай
түзеліп, бір ғана тегіс сызыққа айналады: жүйе істейтін жұмыс дәл осы —
шатасқан кірістен **айқын** нәтиже шығару.

## ✅ Қолдану ережелері

- Белгінің айналасында ең кемі **бір "плитка" радиусындай** бос орын қалдырыңыз.
- Ең кіші өлшемі: **24 px** (одан кішіде `favicon.svg` қолданыңыз).
- Белгіні созбаңыз, көлеңке қоспаңыз, түсін ауыстырмаңыз.
- Жарық фонда `logo-light.svg`, қараңғы фонда `logo-dark.svg`.
- AIQYN атауын әрқашан осылай жазыңыз — бас әріппен де, бөлек те жазбаңыз.
