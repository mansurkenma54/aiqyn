# Өтінімді шынымен жеткізуді қосу

ТЗ талабы: «Интеграция с ЕКЦ 109 для автоматического формирования заявок
на ремонт».

Оператор «Растау» дегенде өтінім **төрт арнамен қатар** кетеді. Ешқайсысы
міндетті емес — бапталғаны ғана жұмыс істейді, ал әр арнаның нәтижесі
квитанцияда ашық жазылады. Жалған «жіберілді» ешқашан қойылмайды.

| Арна | Не істейді | Кілт керек пе |
|---|---|---|
| `ekc109` | 109 форматындағы өтінімді ресми эндпойнтке жібереді | URL берілгенде |
| `email` | Ресми хат: `.docx` құжаты мен фотосы тіркеледі | иә |
| `whatsapp` | Дайын `wa.me` сілтемесі; Cloud API бапталса — автоматты | жоқ / иә |
| `telegram` | Жедел хабарлама (оператордың телефонына) | иә |

Тексеру:

```bash
curl http://localhost:8000/api/delivery/health
```

## 1. Gmail арқылы (өз компьютерінде — ең қарапайымы)

1. Google аккаунтта екі сатылы кіруді қосыңыз —
   https://myaccount.google.com/signinoptions/twosv
2. Қосымша құпиясөз жасаңыз (аккаунт құпиясөзі **емес**) —
   https://myaccount.google.com/apppasswords → атын `AIQYN` деп қойыңыз →
   16 таңбалы код шығады.
3. `.env` файлына жазыңыз:

```
AIQYN_SMTP_HOST=smtp.gmail.com
AIQYN_SMTP_PORT=587
AIQYN_SMTP_USER=sizdin.poshtaniz@gmail.com
AIQYN_SMTP_PASSWORD=<16 таңбалы код, бос орынсыз>
AIQYN_SMTP_FROM=sizdin.poshtaniz@gmail.com
AIQYN_DELIVERY_TO=kimge.baratyn@gmail.com
```

4. Сайтты қайта қосып, сынақ жіберіңіз:

```bash
curl -u admin:<AIQYN_ADMIN_PASSWORD> -X POST http://localhost:8000/api/delivery/test
```

Пошта жәшігіңізге «[AIQYN] … СЫНАҚ …» деген хат келуі керек.

## 2. Vercel-де (интернетте тұрған сайт)

Vercel-де 587-порт жиі жабық, сондықтан SMTP орнына **HTTP пошта API-і**
керек. Brevo тегін 300 хат/күн береді және домен талап етпейді.

1. https://www.brevo.com — тіркелу.
2. **Senders** → өз поштаңызды қосып, растаңыз.
3. **SMTP & API → API Keys** → `Generate a new API key` → көшіру.
4. Vercel-де: жоба → **Settings → Environment Variables** — мыналарды
   қосыңыз (`vercel.json`-ға ЖАЗБАҢЫЗ, ол GitHub-қа шығады):

```
AIQYN_MAIL_PROVIDER      = brevo
AIQYN_BREVO_KEY          = <API кілті>
AIQYN_MAIL_FROM          = <расталған пошта>
AIQYN_DELIVERY_TO        = <кімге баратыны>
AIQYN_PORTAL_PUBLIC_URL  = https://<жоба>.vercel.app
```

5. **Redeploy** басыңыз — Vercel жаңа айнымалыларды тек қайта жинағанда
   ғана алады.

> Vercel-дегі нұсқа — көрсетілім айнасы: дерекқор `/tmp`-та жатады және
> әр суық стартта тазарады. Далалық жұмыс ноутбуктегі сайтта жүреді.

## 3. WhatsApp

Кілтсіз де жұмыс істейді: жүйе әр өтінімге дайын мәтінмен `wa.me`
сілтемесін жасайды. Оператор «Растау» дегеннен кейін «WhatsApp арқылы да
жіберілсін бе?» деген сұрақ шығады — басса, WhatsApp мәтіні дайын күйде
ашылады да, хабарлама шынымен кетеді.

Нөмірді қою:

```
AIQYN_DELIVERY_WHATSAPP=+77012345678
```

Толық автоматты жіберу керек болса — WhatsApp Cloud API (Meta):
`AIQYN_WA_TOKEN` және `AIQYN_WA_PHONE_ID`.

## 4. ЕКЦ 109 — ресми эндпойнт

iKOMEK 109-дың ашық API-і жоқ. Ресми қолжетімділік берілгенде бір жол
қосу жеткілікті — өтінім форматы дайын, кодты өзгертудің қажеті жоқ:

```
AIQYN_109_URL=https://<ресми эндпойнт>
AIQYN_109_TOKEN=<токен>
```

URL қойылмаса, өтінім жергілікті тікет журналына жазылады (аудит ізі),
ал интерфейсте «эндпойнт жоқ» деп ашық көрінеді.

Жіберілетін өтінімнің құрамында **кеңістіктік байланыс** та бар (ТЗ: SDR
және ЦС ГГ НИПД) — ақау нақты жол сегментіне байланады:

```json
{
  "ticket_id": "AIQYN-109-…",
  "category": "Жол жабынының ақауы — шұңқыр",
  "address": "Шымкент, Қаражал көшесі, 47а",
  "lat": 42.3156, "lon": 69.5869,
  "spatial_id": "OSM:way/560025020",
  "osm_way_id": 560025020,
  "road_name": "Жұлдыз",
  "road_class": "residential"
}
```

## 5. Демо кезіндегі қауіпсіздік

**Нақты мемлекеттік мекеменің поштасын келісімсіз қоймаңыз.** Растаусыз
жіберілген ресми өтінім жалған шағым болып саналуы мүмкін.

Сахнада қате мекенжайға хат кетіп қалмауы үшін:

```
AIQYN_DELIVERY_FORCE_TO=ozinizdin.poshtaniz@gmail.com
```

Бұл айнымалы барлығын басып озады: аймақтың өз мекенжайы болса да,
өтінімнің бәрі осы бір поштаға түседі.

Дерекқордағы шартты мекенжайлар (`@aiqyn.local`, `example.kz` сияқты)
жүйе тарапынан **жарамсыз** деп саналады — хат оларға жіберілмейді,
`AIQYN_DELIVERY_TO` қолданылады.

## 6. Тіркемелер

Хатқа тіркеледі: ресми `.docx` құжаты, фото, (сыйса) видео.
Жалпы шек — 7 МБ. Сыймаған файл тіркелмейді, оның орнына хатта жүктеу
сілтемесі қалады. Өтінім «тым үлкен» деген себеппен жоғалмайды.
