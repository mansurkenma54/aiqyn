# AIQYN ZHOL — интернетсіз демо

Хакатон питчингі офлайн өтуі мүмкін. Сондықтан «интернет жоқ» деген
жағдай — қате емес, **қарастырылған жұмыс режимі**.

---

## 1. Не бұрын құлайтын еді

| Не | Неге |
|---|---|
| Оператор картасы | Leaflet пен Font Awesome CDN-нен жүктелетін |
| Барлық белгішелер | Font Awesome шрифті CDN-де |
| Карта фоны | CARTO тақтайшалары |
| Мекенжай | 2ГИС / OSM сұранысы |
| ИИ қорытындысы | Gemini API |

Яғни Wi-Fi құласа, экранда бос ақ бет қалатын.

---

## 2. Қазір не болады

### Кітапханалар — жобаның ішінде

```bash
python scripts/vendor_assets.py     # бір рет, интернет барда
```

Leaflet 1.9.4 және Font Awesome 6.5.2 `portal/static/vendor/` ішіне
көшіріледі (~830 КБ). Одан кейін порталға CDN мүлдем керек емес.

### Карта фоны — үш деңгейлі

```
1. CDN тақтайшалары            (интернет бар)
        ↓ бірде-бір тақтайша келмесе
2. Жергілікті кэш              (scripts/cache_tiles.py жүргізілген болса)
        ↓ кэш те жоқ болса
3. Координаталық тор + белгі   («Байланыс жоқ — координаталар дұрыс»)
```

Үш жағдайдың да ортақ қасиеті: **маркерлер өз орнында қалады.** Leaflet
координатаны фонға тәуелсіз есептейді, сондықтан тақтайша болмаса да
оқиғалар бір-біріне қатысты дұрыс тұрады.

Кэшті алдын ала дайындау (бір рет, интернет барда):

```bash
python scripts/cache_tiles.py --dry-run    # алдымен көлемін көру
python scripts/cache_tiles.py              # ~260 тақтайша, ~3,6 МБ
```

Кэш тек Шымкент шекарасын және тек 11–14 масштабты қамтиды — бұл жаппай
көшіру емес, бір демоға арналған жергілікті көшірме. Атрибуция картада
сақталады.

### Оқиғалар — жергілікті дерекқорда

`portal/aiqyn.db` — SQLite файлы. Ешқандай сыртқы дерекқор жоқ,
сондықтан оқиғалар, статустар, тарих және аймақтар интернетсіз де
толық жұмыс істейді.

### Дәлел медиасы — жергілікті дискіде

`portal/media/{event_id}/photo.jpg` және `clip.mp4`. Порталдың өзі
береді, CDN жоқ.

### Vision → Portal байланысы

Сайт жауап бермесе, құжат `outbox/` қалтасында кезекте тұрады да, сайт
қосылған сәтте автоматты жіберіледі. Далада байланыс жоғалуы — қалыпты
жағдай.

### Сыртқы қызметтер өшкенде

| Қызмет | Не болады |
|---|---|
| 2ГИС / OSM | Мекенжай орнына координата мәтіні жазылады, тізбек тоқтамайды |
| Gemini | ИИ бөлімі жоқ құжат құрылады, тізбек тоқтамайды |
| Telegram | Хабарлама жіберілмейді, қалғаны жұмыс істейді |
| CARTO | Жоғарыдағы үш деңгейлі fallback |

## 3. Демо алдында офлайн тексеру

```bash
# 1. Сайтты қосыңыз
python -m uvicorn portal.app:app --port 8000
```

2. **Wi-Fi-ды өшіріңіз.**
3. <http://localhost:8000> ашыңыз → бас бет толық жүктелуі керек
   (видео да, суреттер де жергілікті).
4. <http://localhost:8000/portal> ашыңыз → тексеріңіз:
   - [ ] сол жақта оқиғалар тізімі бар
   - [ ] картада маркерлер бар
   - [ ] жоғарыда «Байланыс жоқ» белгісі шықты
   - [ ] маркерді басқанда фото мен видео ашылады
   - [ ] «Растау және жіберу» жұмыс істейді
   - [ ] Word құжаты жүктеледі
   - [ ] CSV есебі жүктеледі
5. Wi-Fi-ды қайта қосыңыз → карта фоны өзі оралуы керек
   (бетті жаңарту қажет).

Осы жеті тармақ орындалса, демо интернетке тәуелді емес.
