# AIQYN ZHOL — архитектура

Соңғы жаңарту: **17.08.2026**

## 1. Негізгі бөліну

Жүйе әдейі екі бөлек бағдарлама. Бұл — техникалық ыңғайлылық емес,
өнімдік шешім.

| Бөлік | Қалта | Не істейді | Не істемейді |
|---|---|---|---|
| **AIQYN Vision** | `vision/` | Детекция, дәлел жинау, классификация, мекенжай, құжат құрастыру | Карта көрсетпейді, органға өзі жібермейді |
| **AIQYN Portal** | `portal/` | Құжатты қабылдау, картада көрсету, оператор тексеруі, статус, экспорт | **Ешқандай AI/ML жоқ** |

Неге маңызды:

1. **Камера көзіне тәуелсіздік.** Бүгін — телефон, ертең — Sergek/CCTV
   немесе дрон. `vision/sources/` ішіне бір класс қосылады, қалған код
   өзгермейді.
2. **Порталды бұлтқа шығаруға болады.** Онда torch та, модель салмағы да
   керек емес — Vercel-дегі нұсқа ~1 МБ.
3. **Жауапкершілік шекарасы анық.** Портал ешнәрсені «ойлап таппайды»,
   тек Vision берген құжатты өзгертпей көрсетеді.

## 3. Оқиға объектісі

Барлық жүйе бір объект айналасында құрылған. `evidence/{event_id}.json`
файлы — сол объектінің дискідегі көшірмесі.

Негізгі өрістер:

```jsonc
{
  "event_id": "AIQYN-20260814-211340-77c8b6",  // уақыт + кездейсоқ жұрнақ
  "class_key": "pothole",                       // 4 кластың бірі
  "confidence": 0.742,                          // модель сенімділігі
  "severity": "high",                           // қауіп деңгейі — БӨЛЕК өріс
  "lat": 42.253039,
  "lon": 69.728146,
  "marked_on_road": false,                      // оператор орнын нақтылады ма
  "address_text": "Шымкент, Шамалған көшесі, 34а",
  "timestamp": "2026-08-14T21:13:39+05:00",
  "detector": "yolo",
  "defect_type_official": "Жол жабынының ақауы — шұңқыр",
  "description_text": "…",                      // ресми мәтін, қазақша
  "description_text_ru": "…",                   // орысша
  "responsible_org": "…",
  "map_link_2gis": "…", "map_link_osm": "…"
}
```

**Маңызды ереже:** `confidence` — модельдің сенімділігі, `severity` —
ақаудың қауіптілігі. Бұл екеуі бір нәрсе емес, интерфейсте де, құжатта да
бөлек тұрады.

Статус тізбегі порталда сақталады (`portal/db.py`):

```
тексеруді күтуде → оператор растады → 109-ға жіберілді
   → жұмыс жүргізілуде → қайта тексеру → жабылды
Қосымша нәтижелер: қабылданбады · дубликат · қайта ашылды
```

## 5. Не әдейі жоқ

* **Микросервистер, Kafka, Kubernetes.** Бір ноутбук пен бір FastAPI
  процесі жеткілікті. Жоқ нәрсені схемаға салу — жюриге әлсіздік көрсету.
* **Автоматты жіберу.** Коды бар, бірақ әдепкіде өшірулі: расталмаған
  автоматты өтінім жалған шағым болып саналуы мүмкін.
* **Тұлға/нөмір тану.** Жобаның мақсаты — инфрақұрылым, адам емес.
