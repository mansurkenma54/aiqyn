### Кластар — модель нақты нені шығарады

`models/RDD_best_openvino_model/metadata.yaml` бойынша **тек төртеу**:

| # | Модель атауы | Жүйедегі кілт | Қазақша |
|---|---|---|---|
| 0 | Longitudinal Crack | `crack_longitudinal` | Бойлық жарықшақ |
| 1 | Transverse Crack | `crack_transverse` | Көлденең жарықшақ |
| 2 | Alligator Crack | `crack_alligator` | Торлы жарықшақ |
| 3 | Potholes | `pothole` | Шұңқыр |

> **Маңызды.** Модельде «жолдағы бөгет» (obstruction) класы **жоқ**.
> Ол тек RDD салмағы табылмаған жағдайдағы COCO fallback-те пайда болады
> (`vision/detectors/yolo.py` → `_resolve_weights`) және өнім тарихының
> бөлігі емес. Сайтта ол санат ретінде көрсетілмейді.

### Өлшенген өнімділік

Құрылғы: Windows 11 · Intel Core i5-1135G7 · Intel Iris Xe Graphics (iGPU) ·
OpenVINO 2026.3 · 8 нақты дәлел кадры × 40 өлшеу · conf 0.30 · imgsz 640.

| Құрылғы | Медиана | p95 | Талдау/сек |
|---|---|---|---|

FP16-ға түрлендіру нәтижені өзгертпеді: екі құрылғыда да сол 15 детекция,

Қайта өлшеу:

```bash
python scripts/benchmark.py --runs 40 --limit 8
```

### Дәлдік туралы — ашық айтылады

Бұл модельдің **Шымкент жолдарындағы дәлдігі өлшенбеген.** Сондықтан
жобада accuracy / precision / recall / mAP сандары айтылмайды.

Не бар:
* RDD2022 — 47 420 сурет, 6 ел, 55 000+ белгіленген ақау бойынша
  дайындалған ашық негіз;
* сол негіздегі салмақтың осы құрылғыдағы өлшенген жылдамдығы;
* әр құжатта көрсетілетін нақты `confidence` мәні.

Не жоқ:
* жергілікті ground truth;
* Шымкент деректеріндегі precision/recall.

Жоспар: пилоттың **shadow mode** кезеңінде (2–4 апта) оператордың
растау/қабылдамау шешімдері жиналады, содан кейін ғана жергілікті
дәлдік есептеледі. `docs/pilot-plan.md` қараңыз.

### Белгілі шектеулер

| Шектеу | Салдары |
|---|---|
| Dashcam ракурсында үйретілген | Камера әйнекке ~1,2–1,5 м биіктікте, 15–20° төмен қаралуы керек |
| Кадрдың төменін кесу зиянды | Өлшенді: кесумен 0 ақау, кесусіз сол видеодан 2 ақау |
| Жоғары жылдамдықта кадр бұлдырайды | Ұсынылатын режим: 30–50 км/сағ |
| Жаңбыр, қарсы жарық, көлеңке | Жалған сигнал көбейеді — сондықтан ИИ-сарапшы мен оператор сүзгісі бар |
| Жапония/Үндістан жолдары | Шымкент асфальтының түрі басқа болуы мүмкін — жергілікті валидация қажет |

### Сенімділік ≠ қауіптілік

`confidence` — модельдің «мұнда ақау бар» дегеніне қаншалық сенетіні.
Ол ақаудың **қауіп деңгейі емес**. Интерфейсте бұл екеуі бөлек өріс,
құжат мәтінінде де әдейі ескертіледі.

## 2. ИИ-сарапшы — екінші саты (қосымша)

| Өріс | Мән |
|---|---|
| Рөлі | YOLO тапқан дәлел фотосын қарап, инженерлік қорытынды жазу |
| Модель | Google Gemini (`AIQYN_AI_MODEL`, әдепкі `gemini-2.5-flash`) |
| Ауыстырылады | OpenRouter / Groq / жергілікті модель (`AIQYN_AI_PROVIDER`) |
| Уақыты | ~3–4 сек (README §5.1) |
| Не істейді | Тексеру, өлшем бағалау, жолдағы орны, қауіптілік, ұсынылатын шара, ресми мәтін (kk + ru) |
| Не істемейді | **Шешім қабылдамайды.** Жоққа шығарса да құжат құрылады (`ai_drop_rejected: false`) |
| Өшіру | `config.json` → `"ai_verify": false` |
| Интернетсіз | Өшеді, тізбек тоқтамайды — құжат ИИ бөлімінсіз құрылады |

Жоққа шығарылған детекциялар `evidence/*.rejected.json` болып сақталады —
модельді жақсарту материалы.

Валидация жоспары: пилоттың түнгі рейсінде жанбаған шамдардың қолмен
саналған тізімімен салыстыру.

## 5. Шешім қабылдау тізбегі

```
YOLOv8 (28 мс)          →  «мұнда ақау болуы мүмкін»
дедупликация (25 м)     →  бір ақау бір рет
ИИ-сарапшы (~3 сек)     →  сипаттама + ресми мәтін  [кеңес]
дәлел (8 сек клип+фото) →  тексерілетін материал
ОПЕРАТОР                →  РАСТАУ / ҚАБЫЛДАМАУ      [шешім]
```

**AI шешім қабылдамайды. AI тексерілетін дәлел дайындайды.**

Автоматты жіберу режимі техникалық бар, бірақ `.env` ішінде әдепкіде
**өшірулі** (`AIQYN_AUTO_SEND`), әрі солай қалғаны дұрыс: расталмаған
автоматты өтінім жалған шағым болып саналуы мүмкін.
