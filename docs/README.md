## Сандарды қайта өлшеу

```bash
python scripts/benchmark.py --runs 40 --limit 8
```

Нәтиже `docs/benchmark.json` файлына жазылады. Сайттағы «Модель картасы»
бөліміндегі сандар осы файлдан алынған.

## Демо алдында бір рет

```bash
python scripts/vendor_assets.py    # Leaflet + Font Awesome жобаның ішіне
python scripts/cache_tiles.py      # Шымкент картасының офлайн көшірмесі
python scripts/benchmark.py        # өлшемдерді жаңарту
```
