# AIQYN ZHOL — демо сценарийі

Мақсаты: 3 минутта жюриге бес критерийдің бесеуін де көрсету.
Ең маңызды ереже — **интернетке тәуелді бір де бір қадам болмауы керек.**

---

## 0. Демоға дейін 15 минут

```bash
cd aiqyn

# 1. Сайт қосулы ма
python -m uvicorn portal.app:app --port 8000

# 2. Өлшемдер жаңа ма (сайттағы сандар осыдан келеді)
python scripts/benchmark.py --runs 40 --limit 8

# 3. Интернет үзілсе де карта фоны болуы үшін (бір рет, интернет барда)
python scripts/cache_tiles.py

# 4. Кітапханалар мен шрифттер жобаның ішінде ме (бір рет)
python scripts/vendor_assets.py

# 5. Онлайн сілтемедегі демо деректерін жаңарту
python scripts/export_demo.py && vercel --prod
```

Сақтық көшірме сілтеме (ноутбук істен шықса, телефоннан ашуға болады):
<https://aiqyn-alpha.vercel.app>

Тексеру тізімі:

- [ ] <http://localhost:8000> ашылады, hero видеосы ойнайды
- [ ] <http://localhost:8000/portal> ашылады, картада маркерлер бар
- [ ] Wi-Fi-ды **өшіріп** көріңіз: портал ашылады, «Байланыс жоқ» белгісі
      шығады, маркерлер орнында қалады
- [ ] Бір оқиғаны ашып, Word құжатын жүктеп көріңіз
- [ ] Сақтандыру видеосы дайын тұр — `evidence/*.mp4` ішіндегі кез келген
      нақты далалық клип жарайды (олар — 14 тамыздағы рейстің жазбасы)
- [ ] Экран жазбасы дайын (бәрі құласа — соңғы сақтандыру)

## 2. Сақтандыру нұсқалары

| Не құлады | Не істеу керек |
|---|---|
| Интернет жоқ | Ештеңе. Портал жергілікті жұмыс істейді, карта фоны кэштен немесе торға ауысады |
| Телефон қосылмады | Кез келген нақты жол видеосынан жіберу:<br>`python -m vision.main run --source file --video evidence\AIQYN-20260814-211340-77c8b6.mp4 --lat 42.3417 --lon 69.5901`<br>(`simulator/out/*.mp4` **жарамайды** — олар синтетикалық 2D көрініс, модель онда ақау таппайды) |

## 3. Жиі қойылатын сұрақтарға жауап

**«Неге дәл патруль көлігі?»**
Ол онсыз да күнделікті маршрутта жүреді. Бөлек инспекция маршрутын
құрудың орнына бар қозғалысты деректер қабатына айналдырамыз.

**«Жалған детекция ше?»**
Модель сенімділігі — соңғы шешім емес. Оқиға оператор кезегіне түседі;
оператор растайды, санатын өзгертеді немесе себебін көрсетіп қабылдамайды.
Қабылданбағаны да сақталады — модельді жақсарту материалы.

**«Бір шұңқыр 10 рет түссе ше?»**
Гео (25 м) + уақыт + класс бойынша дубликат кандидаты жасалады. Визуалдық
ұқсастық бойынша біріктіру — пилот жоспарында.

**«Қазақстан жолдары RDD2022-ге сәйкес пе?»**
Ашық негіз бар, бірақ жергілікті валидация бөлек қажет. Сондықтан
shadow-mode пилоты жергілікті ground truth жинайды.

**«109-ға шынымен қосылғансыздар ма?»**
Жоқ. Қазір 109 demo adapter бар — жобаның өз ішіндегі mock-endpoint.
Ресми интеграция пилот кезінде, ресми интерфейс арқылы жасалады. Біз оны
интерфейсте де солай жазып қойдық.

**«Кім қолданады, кім төлейді?»**
Қолданушы — оператор/диспетчер және жол қызметінің маманы. Сатып алушы —
әкімдік / цифрландыру басқармасы. Модель B2G: лицензия + орнату + қолдау.

**«Неге бетте accuracy пайызы жоқ?»**
Өлшемегендіктен. Өлшенбеген санды көрсету — жүйеге деген сенімді
жоғалтудың ең қысқа жолы.
