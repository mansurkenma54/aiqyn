## B · Жобада өлшенген деректер

Барлығы `docs/benchmark.json` файлында, қайта өлшеу:

```bash
python scripts/benchmark.py --runs 40 --limit 8
```

**Тексеру құрылғысы:** Windows 11 · Intel Core i5-1135G7 (Tiger Lake) ·
Intel Iris Xe Graphics (iGPU) · OpenVINO 2026.3 · Ultralytics 8.4.118 ·
imgsz 640 · conf 0.30 · 8 нақты дәлел кадры × 40 өлшеу.

| Тұжырым | Өлшенген мән | Әдісі |
|---|---|---|
| Бір кадрды талдау — **Intel Iris Xe** | медиана **28,3 мс** · p95 30,2 мс | OpenVINO FP16, `RDD_best_openvino_model` |
| Бір кадрды талдау — **процессор** | медиана **86,0 мс** · p95 107,7 мс | PyTorch `.pt`, CPU |
| Талдау жылдамдығы — Iris Xe | **35,4 талдау/сек** | 1000 / медиана |
| Талдау жылдамдығы — процессор | **11,6 талдау/сек** | 1000 / медиана |
| FP16-ға түрлендіру нәтижені өзгертпейді | екі құрылғыда да **15 детекция**, кластары бірдей | сол benchmark |
| **Кадрдан дайын құжатқа дейін** | медиана **15,0 сек** · ең жылдам 7,7 · p90 21,1 | 62 нақты оқиға: `evidence/*.json` `timestamp` → файлдың жазылу уақыты |
| Дәлел клипі — **8 секунд** | 3 сек оқиғаға дейін + 5 сек кейін | `config.json`: `pre_roll_sec` 3.0 + `post_roll_sec` 5.0 |
| Сенімділік шегі **0,30** өлшеніп таңдалды | 0,45-те қиратылған асфальт пен көлеңкедегі ақау жоғалады | `config.json` `_conf_comment` |
| Дәлдеу режимі (tile) детекцияны арттырады | **3 → 11** детекция | `config.json` `_tile_comment` |
| Кадрдың төменін кесу ақауды жоғалтады | кесумен **0**, кесусіз **2** ақау | `README.md` §4, далалық өлшем |
| GPS дәлдігі далалық тесте | **±6 м** | IP Webcam `gps.json`, 14.08.2026 тесті |
| **Кеңістіктік байланыс** | 81 оқиғаның **68-і** нақты жол сегментіне байланды | `portal/spatial.py` · OpenStreetMap Overpass · `python scripts/bind_spatial.py` |
| **GPS-пен тіркелген оқиғалар** | тамыз 2026: **72** оқиға нақты GPS координатасымен (барлығы 108; 32-сі әдепкі координатада — видеофайл/фото тесттері, 4-інде координата жоқ) | `evidence/*.json` + `portal/aiqyn.db*` бірегей `event_id` бойынша · landing «Далалық тест» |
| **ИИ растау үлесі** | тексерілген 60 оқиғаның **14-і** расталды (23%) | `GET /api/analytics` → `quality.ai_confirm_rate` |

### «30 кадр/сек» туралы — дұрыс тұжырымдау

Видео **30 кадр/сек** жылдамдықпен ойналады, ал детектор бөлек ағында
жұмыс істейді (`async_detect: true`) және соңғы кадрды алады. Осы
ноутбукте детектор Iris Xe-де **35,4 талдау/сек** үлгереді, яғни 30 fps
ағынды толық қуып жетеді.

**Дұрыс:** «30 кадр/сек ағын, Intel Iris Xe-де 35 талдау/сек — детектор
кадрдан қалмайды.»
**Бұрыс:** «Біздің AI 30 FPS жұмыс істейді» (құрылғысы мен әдісі жоқ).

## E · Алынып тасталған тұжырымдар

| Болған | Неге алынды |
|---|---|
| «**0 ₸** қосымша патруль» | Камера, орнату, edge-құрылғы, қолдау шығыны есепке алынбаған. Ақиқат емес. Орнына: «жаңа маршрут та, қосымша қызметкер де қажет емес» деген **процестік** артықшылық қалды. |
| Hero-дағы «тірі» телеметрия (кадр/сек, талдау/сек, табылған ақау санауышы) | `Math.random()` арқылы жасалатын **жалған сандар** еді. Алынды; орнына нақты өлшенген мәндер әдісімен бірге көрсетіледі. |
| «Тірі лента» — көше аттары мен пайыздар | HTML ішіне қатып жазылған, бірақ тірі ағын сияқты көрінетін. Алынды. |
| «**Жолдағы бөгет**» — анықталатын санат | Модельде ондай класс **жоқ** (`metadata.yaml`: 4 класс қана). Ол тек RDD салмағы табылмағанда қосылатын COCO fallback. Landing-тен алынды. |
| «Түнде жанбаған шамдарды санайды» — жұмыс істеп тұрған функция | `config.json`: `enable_streetlight: false`. Детектор коды бар, бірақ **әдепкіде өшірулі** әрі RDD2022-мен дәлелденбейді. Landing-те **ПРОТОТИП** белгісімен, бөлек pipeline ретінде көрсетіледі. |
| «Су басу» — анықталатын санат | `enable_flood: false`. Ереже негізіндегі прототип. Сол белгімен көрсетіледі. |
| «Дәлдік / accuracy / mAP» пайызы | Шымкент деректерінде өлшенбеген. Айтылмайды. Орнына: RDD2022 негізі + «жергілікті валидация — пилоттың келесі кезеңі». |

## Тексеру тәртібі

1. Landing-те жаңа сан пайда болса — алдымен осы файлға жол қосылады.
2. B санатындағы сан өзгерсе — `python scripts/benchmark.py` қайта
   жүргізіліп, `docs/benchmark.json` жаңарады.
3. Демо күні таңертең: A санатындағы екі сыртқы сан қайта ашылып тексеріледі.
4. E санатындағы тұжырым қайта қосылмайды.
