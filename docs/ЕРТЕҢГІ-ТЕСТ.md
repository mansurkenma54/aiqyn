# Далалық тест — қадам бақадам

Бұл файл ертеңгі тестке арналған. Қасыңызда телефон болса жеткілікті,
басқа ештеңе есте сақтаудың қажеті жоқ.

---

## 0. Жүрер алдында (5 минут, үйде)

### 0.1 Ноутбукта сайтты қосыңыз

`aiqyn` қалтасындағы **`1-САЙТТЫ-ҚОСУ.bat`** файлын екі рет басыңыз.
Браузер өзі ашылады: <http://localhost:8000>

Терезені ЖАППАҢЫЗ — сайт сол терезеде жұмыс істеп тұрады.

### 0.2 Телефонды дайындаңыз

| # | Қадам | Қайдан |
|---|---|---|
| 1 | **IP Webcam** қосымшасын ашыңыз | телефон |
| 2 | Ең төменге сырғытып **«Start server»** басыңыз | IP Webcam |
| 3 | **USB кабельмен** ноутбукке жалғаңыз | — |
| 4 | Параметрлер → Байланыстар → Модем режимі → **USB модем: ҚОСУ** | телефон |
| 5 | GPS (Геолокация) **ҚОСУЛЫ** екеніне көз жеткізіңіз | телефон |

**GPS туралы:** тексерілді — жұмыс істейді, дәлдігі ±6 метр.

Телефонның мекенжайын есте сақтаудың қажеті жоқ: **USB модемді қайта
қосқан сайын IP өзгереді, бірақ жүйе телефонды желіден өзі тауып алады**
(журналда «Телефон табылды: http://...» деп жазады).

Қолмен тексергіңіз келсе: браузерден `http://<телефон-IP>:8080/gps.json`
ашыңыз — ішінде `latitude` мен `longitude` болуы тиіс. (Ескерту:
`sensors.json` бұл нұсқада бос `{}` қайтарады — бұл қалыпты жағдай,
GPS `gps.json` ішінде тұр.)

### 0.3 Бәрін бір команданың өзімен тексеріңіз

**`3-ТЕКСЕРУ.bat`** файлын басыңыз. Мынадай болуы керек:

```
[ OK ] Телефон жауап берді: http://10.211.38.104:8080
[ OK ] GPS жұмыс істеп тұр: 42.34xxx, 69.59xxx
[ OK ] ИИ-тексеруші: gemini / gemini-2.5-flash
[ OK ] 2ГИС мекенжайы қосулы
[ OK ] Сайт жұмыс істеп тұр
```

Барлығы `OK` болса — жүруге болады.

## 1. Телефонды машинаға бекіту

Бұл — ең маңызды қадам. Модель **dashcam ракурсында** үйретілген.

- Телефонды **әйнектің ортасына**, көзге жақын биіктікке бекітіңіз
- Камера **15–20° төмен** қарасын
- **Кадрдың кемінде 60%-ы ЖОЛ болуы керек**
- Панель (торпедо) кадрдың төменгі жағын жауып тұрса — қалыпты жағдай,
  оны программа кесіп тастайды (`--crop-bottom`)

Дұрыс емес: телефон тік тұр, кадрдың жартысы аспан немесе панель.
Дұрыс: көкжиек кадрдың жоғарғы 1/3-інде, жол — қалған бөлігінде.

## 2. Іске қосу

`aiqyn` қалтасында **`2-ЖОЛҒА-ШЫҒУ.bat`** файлын басыңыз.

Немесе қолмен:

```bash
cd "C:\Users\Acer\Desktop\smart citi\aiqyn" && python -m vision.main run --crop-bottom 0.30
```

Экранда терезе ашылады. Онда көретініңіз:

- жоғарыда қара жолақ: **REC ● AI ROAD SCAN**, координата, уақыт
- жолда **көгілдір сызықтар** (жол шекаралары)
- ақау табылғанда **қызыл тіктөртбұрыш** + нөмір (`01`, `02`)
- төменгі сол жақта: FPS, табылған ақау саны, GPS күйі

**Пернелер:** `q` — шығу · `d` — панельді жасыру · `Space` — кідірту

## 3. Қалай жүру керек

| Не | Қалай |
|---|---|
| Жылдамдық | **30–50 км/сағ** (жоғары жылдамдықта кадр бұлдырайды) |
| Маршрут | Ақауы көп деп білетін көшелерді таңдаңыз |
| Ауа райы | Күндіз, құрғақ. Күн батарда қарсы жарық болмасын |
| Ұзақтығы | Алғашқы тестке **15–20 минут** жеткілікті |

Ноутбукты қасыңыздағы адам ұстасын — экранды бақылап отыру керек.

## 4. Далада нені бақылау

| Көрініс | Мағынасы | Не істеу |
|---|---|---|
| GPS: **OK** | координата келіп тұр | жақсы |
| GPS: **ЖОҚ** | телефон GPS бермей тұр | ашық жерге шығыңыз, 1-2 мин күтіңіз |
| Ақау табылмайды | камера бұрышы немесе шек жоғары | төменгі бөлімді қараңыз |
| Тым көп ақау | шек тым төмен | `--conf 0.65` қойыңыз |
| FPS 5-тен төмен | ноутбук үлгермей жатыр | `--stride 8` қойыңыз |

Ақау табылған сайын журналда мынадай жол шығады:

```
АҚАУ ТАБЫЛДЫ: pothole (72%) @ 42.34170, 69.59010 [phone] -> AIQYN-...
ИИ тексерді (3.2 сек): РАСТАДЫ — pothole (90%)
ҚҰЖАТ ДАЙЫН: ... | Жол жабынының ақауы — шұңқыр | Шымкент, ... көшесі, 21
Құжат сайтқа жіберілді
```

Осы төрт жол шықса — тізбек толық жұмыс істеп тұр.

## 5. Оралғаннан кейін

1. Браузерден <http://localhost:8000/portal> ашыңыз
2. Картада маркерлер тұруы керек — **дәл жолдың үстінде**
3. Маркерді басыңыз → фото, видео, мекенжай, ИИ талдауы көрінеді
4. **«Оператор»** → кіріңіз (`admin` / `aiqyn2026`)
5. Бір құжатты ашып, **«⬇ Word құжаты»** басыңыз — файл жүктеледі
6. **«Растау және жіберу»** басыңыз — mock-109 тікеті жазылады

Барлық дәлел `aiqyn\evidence\` қалтасында да сақталады:
`{ID}.jpg` (белгіленген), `{ID}_raw.jpg` (түпнұсқа), `{ID}.mp4`, `{ID}.json`

## 6. Видеомен тест (телефонсыз да болады)

Егер телефон қосылмай қалса немесе жолға шыға алмасаңыз — **бұрын
жазылған видеомен дәл сол тізбек толық жұмыс істейді**:

```bash
cd "C:\Users\Acer\Desktop\smart citi\aiqyn" && python -m vision.main run --source file --video "..\тексеру\WhatsApp Video 2026-08-13 at 19.24.06.mp4" --lat 42.3417 --lon 69.5901 --crop-bottom 0.28
```

- `--source file --video <жол>` — видеофайлдан оқу
- `--lat/--lon` — видеода GPS болмағандықтан координатаны қолмен беру
- `--fast` қоссаңыз — нақты уақытты күтпей, барынша тез өңдейді

Телефонмен жазылған кез келген видео жарайды (mp4, mov).
**Жюриге көрсету кезінде осы режим — сақтандыру полисі.**

Суреттен де жасауға болады:

```bash
python -m vision.main images "C:\фотолар" --lat 42.3417 --lon 69.5901
```

## 7. Мәселе шықса

| Мәселе | Шешімі |
|---|---|
| Телефон табылмайды | `python -m vision.main scan` — желіні өзі іздейді |
| Мекенжай басқа болса | `--phone-host 192.168.x.x` |
| `sensors.json` бос `{}` | IP Webcam параметрлерінде Location деректерін қосыңыз; Android → Қосымшалар → IP Webcam → Рұқсаттар → Орналасқан жер: **Рұқсат** |
| GPS мүлдем істемесе | `--lat 42.3417 --lon 69.5901` (тест тоқтамайды) |
| Ақау табылмайды | камераны төмен қаратыңыз, `--conf 0.45` қойыңыз |
| Тым көп жалған ақау | `--conf 0.7` қойыңыз (ИИ-тексеруші оны әлдеқашан сүзеді) |
| Сайт жауап бермейді | құжаттар `outbox\` ішінде сақталады, сайт қосылғанда автоматты жіберіледі |
| Ноутбук қызып кетті | `--stride 10 --no-preview` |
| Жөндеу жүріп жатқан жерден өттік | ол аймақ картада белгіленген болса, өтінім автоматты жіберілмейді |

## 8. Ең қажет 5 команда

```bash
# тексеру
python -m vision.main doctor

# телефоннан (негізгі режим)
python -m vision.main run --crop-bottom 0.30

# видеофайлдан
python -m vision.main run --source file --video жол.mp4 --lat 42.34 --lon 69.59

# суреттерден
python -m vision.main images C:\фотолар

# телефонды желіден іздеу
python -m vision.main scan
```
