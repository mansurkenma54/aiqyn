# AIQYN ZHOL — деректер және құпиялық

Соңғы жаңарту: **17.08.2026**

## Негізгі ұстаным

> **Жүйенің мақсаты — жол инфрақұрылымын бақылау. Адамды бақылау емес.**

Бұл жай ұран емес, техникалық шешім: модель тек жол жабынының ақауын
анықтайды, оның кластары төртеу және олардың ешқайсысы адамға да,
көлікке де қатысты емес (`docs/model-card.md`).

---

## 1. Қандай дерек жиналады

| Дерек | Не үшін | Қайда сақталады |
|---|---|---|
| Ақаудың фотосы (белгіленген) | Ресми құжатқа дәлел | `evidence/{id}.jpg` |
| Ақаудың фотосы (өңделмеген) | Дау туған жағдайда түпнұсқа | `evidence/{id}_raw.jpg` |
| 8 секундтық видео | Контекст: ақау шынымен жолда ма | `evidence/{id}.mp4` |
| GPS координатасы + уақыт | Орнын анықтау | `evidence/{id}.json` |
| Мекенжай мәтіні | Ресми құжат | сол JSON |
| Модель сенімділігі, санат | Оператордың шешімі үшін | сол JSON |
| Оператордың әрекеті | Аудит | `portal/aiqyn.db` |

**Жиналмайды:** тұлға идентификаторы, көлік нөмірінің мәтіні, жүргізушінің
жеке деректері, дыбыс.

---

## 2. Деректің азайтылуы

* **Шикі видео сыртқа шықпайды.** Талдау көліктің ішінде жүреді, порталға
  тек дайын оқиға (фото + 8 сек клип + метадерек) кетеді.
* Клип қысқа: оқиғаға дейін 3 секунд, кейін 5 секунд
  (`config.json`: `pre_roll_sec`, `post_roll_sec`).
* Дәлел клипінің ені 960 px-ке дейін кішірейтіледі (`clip_width`).
  Ресми фото толық сапада қалады.
* Кадрдың жол емес бөлігі құжатқа қажет емес — бірақ **кесу әдейі
  жасалмайды**, себебі өлшенді: кесу шұңқырды да жоғалтады
  (`crop_bottom_frac: 0`).

## 3. Пилот алдында міндетті түрде қосылатын нәрселер

Бұл тізім — қазір **жоқ**. Оны жасырмаймыз.

| Талап | Күйі | Не істеу керек |
|---|---|---|
| Кездейсоқ түскен бет-әлпетті бұлдырату | ⬜ жоқ | Дәлел кадрында адам болса, автоматты blur |
| Көлік нөмірін бұлдырату | ⬜ жоқ | Құжатқа қажет емес — blur қосылады |
| Медианы сақтау мерзімі | ⬜ анықталмаған | Әкімдікпен келісіледі (ұсыныс: расталған оқиға — іс жабылғанша + N ай; қабылданбағаны — 30 күн) |
| Шикі видеоны бөлек сақтау саясаты | ⬜ жоқ | Шикі ағын мүлдем сақталмайды деп бекіту |
| Кіру бақылауы (SSO/RBAC) | ⚠️ бір оператор | `admin` + `.env` құпия сөзі, камера арнасы — `AIQYN_INGEST_TOKEN`. Пилотта сервер сессиясы + рөлдер |
| Аудит журналы | ⚠️ ішінара | Оператор әрекеті дерекқорда бар; толық аудит трейл қосылады |
| Шифрланған тасымал | ⬜ жергілікті HTTP | Пилотта HTTPS міндетті |
| Кілттерді сақтау | ⚠️ `.env` файлы | Пилотта secret manager |
| Резервтік көшірме | ⬜ жоқ | Пилотта міндетті |

## 4. Заңдық ескерту (демо кезеңі)

* Демо кезінде **нақты мемлекеттік мекеменің поштасы қойылмаған.**
  Растаусыз ресми өтінім жіберу жалған шағым болып саналады. Хакатонда
  `/mock/109/tickets` эндпойнті қолданылады.
* Автоматты жіберу мүмкіндігі бар, бірақ `.env` ішінде **әдепкіде
  өшірулі** (`AIQYN_AUTO_SEND`). Ол әкімдікпен келісілгеннен кейін ғана
  қосылады.
* Жөндеу аймақтары `scripts/seed_zones.py` арқылы қосылғанда, олар
  **анықтамалық шеңбер** болып тұрады және AI құжатын тоқтатпайды. Нақты
  шекара ресми құжатпен расталып, оператор «Шекараны оператор нақтылады»
  белгісін қойғаннан кейін ғана автоматты тоқтату іске қосылады.

## 5. Пайдаланылатын сыртқы қызметтер

| Қызмет | Не жіберіледі | Өшіруге бола ма |
|---|---|---|
| Google Gemini (ИИ-сарапшы) | Ақаудың дәлел фотосы + метадерек | Иә: `config.json` → `"ai_verify": false` |
| 2ГИС (геокодтау) | Координата | Иә, OSM-ге ауысады |
| OpenStreetMap Nominatim | Координата | Иә, координата мәтіні қалады |
| CARTO (карта фоны) | Тақтайша сұранысы | Иә, жергілікті кэш немесе тор фоны |
| Telegram (хабарлама) | Фото + мекенжай | Әдепкіде өшірулі |

Барлығы өшірілгенде жүйе жұмысын жалғастырады — тек мекенжай координата
мәтіні болып қалады және ИИ қорытындысы жазылмайды.
